# SmartOne.POS.Releases

Official public distribution repository for SmartOne POS installer releases.

New releases use version-matched assets such as:

- `SmartOne_POS_Server_Setup_<version>.exe`
- `SmartOne_POS_Cashier_Setup_<version>.exe`

Historical releases may still contain `SmartHQ_POS_...` asset filenames. Those published assets are retained for compatibility and should not be renamed or replaced in place.

Application source code is maintained separately in the private SmartOne POS source repository.
